# Report card: Clarity 4 recipes (2026-10-24)

1. Fast: yes. Tests run on a simulated chain on your own computer, with no internet after `npm install`.
2. All your devices: yes. Plain files plus Node, so it runs on a Mac, a Pi or a Windows PC.
3. Offline: yes, once installed.
4. Works with others: yes. It's public, and anyone can copy it.
5. Outlives us: yes. Plain Clarity files and an open-source test tool, with no company account needed.
6. Private: nothing leaves the machine. There are no keys, no wallets and no personal data, only Clarinet's public test accounts.
7. You're in control: everything is in plain files you can read, copy or delete.
